# CICD-howto

**Repository status:** This repository is no longer actively maintained.

It is retained as a historical reference for the NSO and GitLab CI/CD examples described here. The examples may refer to older NSO, GitLab, and related tooling versions. No current maintenance or support is planned.

For current Cisco NSO documentation, see the [Cisco NSO documentation](https://developer.cisco.com/docs/nso/).

This repo contains a small howto guide for how to implement CICD with NSO using GitLab, as well as some example files that are used in that guide.

You can read the guide either [online](CICD.md) or by cloning the repo and going from there. There is `Makefile` that can build a few different output formats if you have pandoc installed.

Additional topics might be added to this guide, or expanded, if there is interest.

For historical questions, contact vleijon@cisco.com. After archival, new pull requests will not be accepted.
